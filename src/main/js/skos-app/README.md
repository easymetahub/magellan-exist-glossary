# SKOS App (Vite)

This app is now built with Vite + React.

## Available Scripts

In this directory (`src/main/js/skos-app`):

- `npm run dev` or `npm start` - start local dev server.
- `npm run build` - create a production bundle in `build/`.
- `npm run preview` - preview the production bundle locally.
- `npm test` - run tests in watch mode with Vitest.
- `npm run test:ci` - run tests once for CI.

## Notes

- Static assets live in `public/` and are served from `/`.
- `index.html` is the Vite entry file at the project root.
